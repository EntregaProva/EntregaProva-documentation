# Glossário

Termos usados ao longo da documentação do **EntregaProva**.

| Termo | Significado |
| :--- | :--- |
| **Aging** | Tempo de pendência de uma entrega sem comprovante conferido, normalmente agrupado em faixas de dias. |
| **Canhoto** | Parte da nota fiscal assinada pelo recebedor, que comprova a entrega da mercadoria. |
| **Conferente** | Pessoa do faturamento que compara o canhoto fotografado com os dados da nota fiscal. |
| **CT-e** | Conhecimento de Transporte Eletrônico (modelo 57). Documento fiscal do serviço de frete. |
| **Embarcador** | Cliente que contrata o frete e recebe a cobrança da transportadora. |
| **Idempotência** | Propriedade que garante que enviar o mesmo comprovante várias vezes gera um único registro. |
| **LGPD** | Lei Geral de Proteção de Dados. Define como dados pessoais podem ser coletados e tratados. |
| **MoSCoW** | Método de priorização: Must, Should, Could e Won't have. |
| **MVP** | Produto Mínimo Viável. Primeira versão com o menor conjunto de recursos que gera valor. |
| **NF-e** | Nota Fiscal Eletrônica (modelo 55). |
| **OCR** | Reconhecimento óptico de caracteres. Leitura automática de texto em imagens. |
| **POD** | *Proof of Delivery*. Comprovante de entrega. |
| **PWA** | *Progressive Web App*. Aplicação web instalável e responsiva, que dispensa loja de aplicativos. |
| **SEFAZ** | Secretaria da Fazenda estadual, que autoriza e consulta documentos fiscais eletrônicos. |
| **XXE** | *XML External Entity*. Vulnerabilidade em parsers de XML, mitigada na ingestão dos arquivos. |
